AutiGuia
Sobre o projeto

O AutiGuia é um site desenvolvido com o objetivo de oferecer informações e recursos voltados para pessoas com Transtorno do Espectro Autista (TEA), seus familiares, cuidadores e profissionais da área.

A proposta do projeto é facilitar o acesso a informações, oportunidades e recursos de apoio, contribuindo para uma maior inclusão e interação entre as pessoas.
